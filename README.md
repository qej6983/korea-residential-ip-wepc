## 韩国家宽IP 到底是什么，和“韩国 VPS”差在哪

搜“韩国家宽IP”的人，要的是 IP 在数据库里登记成韩国本地家庭宽带，机器放在韩国只是前提，不是全部。

机房 IP 的 ASN 指向云服务商或 IDC，流媒体和社交平台的风控模型很容易识别出这是数据中心流量。原生 IP 要求 IP 段由韩国本土运营商分配、ASN 归属韩国 ISP，但原生 IP 仍可能是机房段。住宅 IP 再进一步，IP 要落在家庭宽带段里。双 ISP 是数据库层面的登记属性，表示这个 IP 在多个 IP 库里都被标记为家宽，不是单一家宽库的孤证。静态 IP 则是每次开机地址不变，做账号环境不会今天首尔明天釜山。
